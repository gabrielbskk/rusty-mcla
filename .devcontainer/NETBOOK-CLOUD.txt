CLOUD DO VOIDBOOK PARA ESTE CODESPACE

A configuração está no branch `netbook-cloud` do repositório `gabrielbskk/rusty-mcla`, que parte do backup do Codespace. O Codespace existente está parado no branch `android-experimental`; ele não recebe essa configuração automaticamente.

Quando a cobrança do GitHub estiver resolvida:
1. Inicie o Codespace existente.
2. No terminal, rode `git fetch origin` e `git switch -c netbook-cloud --track origin/netbook-cloud`.
3. No VS Code, use a paleta de comandos e escolha **Codespaces: Rebuild Container** para ativar Tailscale.
4. Se Tailscale pedir autenticação, rode `sudo tailscale up --accept-routes` e abra o link exibido.
5. Rode `sftp voidbook-cloud` para navegar ou transferir arquivos.

A reconstrução mantém os arquivos do repositório em `/workspaces`, mas pode remover programas e caches instalados fora dessa pasta. Os READMEs e scripts de build do repositório documentam as ferramentas necessárias para reinstalação.

A pasta inicial do SFTP é `/Cloud`; nela ficam `Builds`, `Codespace-Backups` e `GoogleDrive`.

Comandos SFTP úteis:
- `ls` — listar pastas
- `cd Builds/rusty-mcla` — selecionar a pasta de APKs deste projeto
- `put ./caminho/arquivo.apk` — enviar do Codespace ao VoidBook
- `get arquivo.apk` — baixar para o diretório atual do Codespace
- `exit` — fechar o SFTP

A chave e o host SSH confiável são injetados por segredos de Codespaces com acesso limitado aos dois repositórios. A conta SFTP fica confinada à pasta `~/Cloud` do VoidBook e não tem acesso a um shell.
